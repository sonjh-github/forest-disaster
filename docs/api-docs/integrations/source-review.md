## 판독 유의사항

- PDF 본문 텍스트 추출과 별도로 위 페이지들을 PNG로 렌더링해 표·그림을 확인했다.
- 페이지 번호는 PDF 파일의 1부터 시작하는 페이지 번호다.
- LS 연구계획서는 일부 내장 글꼴의 텍스트 추출이 깨져 이미지 판독을 우선했다.
- 구성도에 나타난 물리 회로 핀이나 제품명은 API 필드로 자동 승격하지 않았다.
