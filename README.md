# 산림재난 통합 실증 시스템

산불·산사태 현장의 장비 및 인원 데이터를 수집하고, 산림재난 통합상황판에서 실시간으로 확인하기 위한 실증용 시스템입니다.

## 프로젝트 구성

| 폴더 | 역할 |
| --- | --- |
| `forest-back-demo` | Supabase 연계, 공통·도메인 API, 장비 데이터 수집 백엔드 |
| `forest-api-shoot` | 장비·AI·통신 기능별 연동 요청 및 결과 검증 서버 |
| `forest-front-demo` | 산림재난 사건, 현장 자원, 통신망과 경보를 표시하는 통합상황판 |

## 데이터 흐름

```text
현장 장비·외부 시스템
  → 수집 API
  → 요청 검증 및 Supabase 저장
  → 조회 API
  → 통합상황판 갱신
```

각 프로젝트의 실행 방법과 환경 변수는 해당 폴더의 `README.md` 및 `.env.example`을 참고합니다. 실제 비밀키와 로컬 실행 산출물은 저장소에 포함하지 않습니다.
